# Security policy

Only the latest released 0.1.x version receives fixes. Do not use unsupported package or framework versions on exposed systems.

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/amrachraf6699/laravel-storm/security/advisories/new). If private reporting is unavailable, contact the maintainer through their [GitHub profile](https://github.com/amrachraf6699) to arrange a private channel. Do not post credentials, exploit payloads against third-party targets, or sensitive reports in public issues.

Include affected versions, a minimal authorized/local reproduction, expected behavior, and impact. Load tests should use local or explicitly authorized staging fixtures.
